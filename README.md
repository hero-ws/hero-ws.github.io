# HERo @ ICRA 2027

Website for the proposed HERo workshop at ICRA 2027: https://hero-ws.github.io/.

Created and maintained by Mario Malizia and Ken Hasselmann.

## AI tools used

AI tools, including ChatGPT, assisted in the development of this website. Mario and Ken are responsible for its content and implementation.

## Local preview

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

Run `python3 scripts/check-site.py` and `python3 scripts/check-editorial.py` to check the site.
